# day

**Code reference:** `time%day_mo` ([declaration](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/time_module.f90#L25)).

The day of the month associated with the output row.

Monthly and annual files identify the reporting boundary in this column.

This is an identifier, label, or date component; it has no physical unit.
