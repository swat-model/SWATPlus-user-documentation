# unit

**Code reference:** `iaq` ([declaration](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/aquifer_output.f90#L10)); `"       1"` ([writer](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/basin_aquifer_output.f90#L29)).

Identifies the aquifer represented by an individual-aquifer row. Basin rows print 1 instead of an aquifer identifier.

This is an identifier, label, or date component; it has no physical unit.
