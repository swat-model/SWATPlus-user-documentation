# name

**Code reference:** `ob(iob)%name` ([declaration](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/hydrograph_module.f90#L332)); `bsn%name` ([declaration](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/basin_module.f90#L10)).

The aquifer object name in individual output, or the basin name in basin-average output.

This is an identifier, label, or date component; it has no physical unit.
