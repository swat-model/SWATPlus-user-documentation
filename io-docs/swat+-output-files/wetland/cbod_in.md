# cbod_in

**Code reference:** `wet_in_d(j)%cbod` ([declaration](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/hydrograph_module.f90#L41)).

Carbonaceous biochemical oxygen demand in the incoming hydrograph. This can include routed surface runon, associated tile flow, and overbank inflow from a linked channel. [HRU runon](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/hru_control.f90#L268-L276), [Overbank inflow](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/sd_channel_sediment3.f90#L140-L158)
