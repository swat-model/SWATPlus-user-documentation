# op_var

**Code reference:** `operation-specific value` ([writer](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/actions.f90#L156)).

Operation-specific variable label. This printed slot has no single value declaration: the writer emits operation- or row-type-specific values with different row widths. The code link points to a representative writer, not a universal field mapping.

This field has no physical unit in the output table.

This field belongs to a fixed or event-style report rather than the standard daily/monthly/yearly/average-annual series.
