# div_co3

**Code reference:** `asaltb_d(iaq)%salt(isalt)%div` ([declaration](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/salt_aquifer.f90#L13)).

Aquifer diversion slot for carbonate. The header describes signed exchange, with removal negative and addition positive. The inspected 1-D path leaves the field at zero because no active producer assigns it. See [daily aquifer values](aquifer-salt.md#daily-1-d-aquifer-values).

**Unit:** kg.

The same printed heading can appear in daily, monthly, yearly, and average-annual variants of this family. The reporting interval changes the row period; this page does not infer a total-versus-average rule beyond what the family output and source establish.
