# urb_kg

**Code reference:** `salt_basin(4)` ([calculation](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/salt_balance.f90#L81-L88)).

Salt in the urban runoff diagnostic. Its daily slot remains zero on the inspected revision because it has no active producer. [HRU salt diagnostics](../hru-salt/README.md)

**Unit:** kg for daily, monthly, and yearly output. The average-annual value is kg/yr.
