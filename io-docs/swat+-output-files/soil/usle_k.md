# usle_k

**Code reference:** `soil(j)%ly(ly)%usle_k` ([declaration](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/soil_module.f90#L13)).

USLE erodibility factor from the model soil-layer property record. Custom layers use the mean over the corresponding depth interval. [Model layer initialization](README.md#how-the-model-builds-the-printed-layers)

This field has no physical unit in the output table.
