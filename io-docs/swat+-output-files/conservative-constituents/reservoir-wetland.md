# Reservoir and wetland

Both report families use the `res_cs` row in [print.prt](../../introduction-1/simulation-settings/print.prt/README.md) and print the same headings. The wetland writer skips the diversion group, which shifts the stored mass, concentration, and volume values. The individual pages show the values each writer produces.
