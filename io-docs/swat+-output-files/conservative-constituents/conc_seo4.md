# conc_seo4

**Code reference:** `hcsb_d(j)%cs(ics)%srbd` ([declaration](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/cs_module.f90#L28)).

The printed heading denotes soil-water concentration (g/m3). With three configured constituents, the value at this position is sorbed constituent mass in kg/ha. See the [reporting periods](hru.md#reporting-periods) for aggregation.
