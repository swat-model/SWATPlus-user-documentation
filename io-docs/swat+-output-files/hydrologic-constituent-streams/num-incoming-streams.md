# num

Object number within its type of the receiving object.

Position 8 of the incoming data prefix carries this value. Each row in the dormant writer represents one incoming connection of the receiving object. [Data write](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/hcsin_output.f90#L22)

This field has no physical unit.
