# solp_stor

**Code reference:** `res(j)%solp` ([declaration](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/hydrograph_module.f90#L37)).

Soluble phosphorus remaining in the reservoir on the reporting date. GWFlow exchange, allocation withdrawal, settling, and release can all change this mass. [Nutrient block details](README.md#what-the-nutrient-blocks-include).

**Unit:** kg P.

The writer reports the current storage in all four periods.
