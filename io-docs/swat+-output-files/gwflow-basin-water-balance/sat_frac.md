# sat_frac

**Code reference:** `frac_sat` ([declaration](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/gwflow_output.f90#L576)).

The number of active cells contributing saturation-excess flow divided by the number of active cells. This is a cell-count fraction, not an area-weighted saturated fraction.

**Unit:** fraction.

This field appears in the daily file only; it is not a column in the monthly, yearly, or average-annual basin water-balance files.
