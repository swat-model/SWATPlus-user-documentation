# vbef

**Code reference:** `vbef_grid` ([declaration](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/gwflow_module.f90#L154)).

Groundwater storage before the daily balance, summed across active groundwater cells and converted to an equivalent depth over the total basin area.

**Unit:** mm.

This field appears in the daily file only; it is not a column in the monthly, yearly, or average-annual basin water-balance files.
