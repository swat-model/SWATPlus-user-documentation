# p20

**Code reference:** `ob(icmd)%fdc%p_md%p(9)` ([declaration](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/hydrograph_module.f90#L299)).

The printed heading `p20` is associated with nominal 20% exceedance. The annual curve selects ranked day 73 from flows sorted in descending order, using the [fixed rank table](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/hydrograph_module.f90#L304). The writer takes the median of the annual values at this rank. See the [table notes on partial years](README.md).

**Unit:** m3/s.

This field belongs to a fixed or event-style report rather than the standard daily/monthly/yearly/average-annual series.
