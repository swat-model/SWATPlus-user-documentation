# 3:1.5.2 Nitrogen Dry Deposition

Dry deposition of nitrate and ammonia is input to the model for each subbasin. Average daily deposition is added to the appropriate surface soil pool.

$$NO_{3_{ly=1}}=NO_{3_{ly=1}}+NO_{3_{drydep}}$$                                                                                                                       3:1.5.3

$$NH_{4_{ly=1}}=NH_{4_{ly=1}}+NH_{4_{drydep}}$$                                                                                                                      3:1.5.4

where $$NO_{3_{ly=1}}$$ is the $$NO_3$$ in the surface soil layer, $$NH_{4_{ly=1}}$$ is the ammonium in the surface soil layer, $$NO_{3_{drydep}}$$ is the daily nitrate dry deposition rate (kg/ha) and $$NH_{4_{drydep}}$$ is the daily ammonium dry deposition rate (kg/ha).

Table 3:1-5: SWAT+ input variables that pertain to dry deposition.

| Definition                                | Source Name | Input Name | Input File |
| ----------------------------------------- | ----------- | ---------- | ---------- |
| Daily nitrate dry deposition rate (kg/ha) | drydep\_no3 |            | .atm       |
| Daily ammonia dry deposition rate (kg/ha) | drydep\_nh4 |            | .atm       |
