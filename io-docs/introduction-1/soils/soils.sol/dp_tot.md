# dp\_tot

**Code reference:** `soildb(isol)%s%zmx` ([declaration](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/soil_data_module.f90#L67)).

If no maximum rooting depth is specified, the model assumes that the roots can develop throughout the entire depth of the soil profile.
