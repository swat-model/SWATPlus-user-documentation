# lai

**Code reference:** `transpl(ic)%lai` ([declaration](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/plant_data_module.f90#L156)).

Initial leaf area index in square meters per square meter. This value is read from the file but is not actively applied to the crop LAI during transplanting.
