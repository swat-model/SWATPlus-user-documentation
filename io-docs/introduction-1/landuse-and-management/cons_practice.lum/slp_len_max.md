# slp\_len\_max

**Code reference:** `cons_prac(icp)%sl_len_mx` ([declaration](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/landuse_data_module.f90#L53)).

This value is the maximum slope length, in meters, used for the conservation practice. SWAT+ uses the lesser of the HRU slope length and this value when initializing the slope-length factor. The example value is 121.0 m.
