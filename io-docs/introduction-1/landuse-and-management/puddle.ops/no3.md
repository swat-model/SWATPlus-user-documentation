# no3

**Code reference:** `pudl_db(ic)%no3` ([declaration](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/mgt_operations_module.f90#L23)).

This field holds the nitrate nitrogen concentration specified for puddling. It is read from the file, but the current puddling routines do not apply it. Keep the field in each row so the remaining values stay in the correct columns.
