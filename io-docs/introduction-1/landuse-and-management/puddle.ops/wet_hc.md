# wet_hc

**Code reference:** `pudl_db(ic)%wet_hc` ([declaration](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/mgt_operations_module.f90#L19)).

This value sets the hydraulic conductivity of the upper soil layer when the puddling operation is performed. A positive value replaces the current value; zero leaves the current value unchanged.
