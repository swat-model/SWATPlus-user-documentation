# solp

**Code reference:** `pudl_db(ic)%solp` ([declaration](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/mgt_operations_module.f90#L24)).

This field holds the soluble phosphorus concentration specified for puddling. It is read from the file, but the current puddling routines do not apply it. Keep the field in each row so the remaining values stay in the correct columns.
