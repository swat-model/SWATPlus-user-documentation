# lat

**Code reference:** `mallo(imro)%src(i)%lat` ([declaration](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/manure_allocation_module.f90#L29), [read](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/manure_allocation_read.f90#L68)).

Real coordinate (default `0.0`) giving the latitude of the manure source object.

*(Note: In SWAT+ main (6f515368), this column is parsed into memory but is not used in simulation calculations).*
