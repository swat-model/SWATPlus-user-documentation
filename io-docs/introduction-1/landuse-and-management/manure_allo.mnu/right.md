# right

**Code reference:** `mallo(imro)%trn(i)%right` ([declaration](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/manure_allocation_module.f90#L47), [read](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/manure_allocation_read.f90#L95)).

Character string (`len=2`, default `""`) intended to designate senior (`sr`) or junior (`jr`) manure priority rights.

*(Note: In SWAT+ main (6f515368), this column is parsed into memory but is not used in simulation calculations).*
