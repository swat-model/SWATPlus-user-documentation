# ovn\_mean

**Code reference:** `overland_n(il)%ovn` ([declaration](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/landuse_data_module.f90#L59)).

This is the value that is used by the model. The [ovn\_min](ovn_min.md) and [ovn\_max](ovn_max.md) values are included in the file to help users stay within reasonable ranges during calibration.
