# name (landuse.lum)

The name of the land use and management record is a primary key referenced by [lu\_mgt](../../hydrologic-response-units/hru-data.hru/lu_mgt.md) in [**hru-data.hru**](../../hydrologic-response-units/hru-data.hru/). All names in the **landuse.lum** file must be unique.
