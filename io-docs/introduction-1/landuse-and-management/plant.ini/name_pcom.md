# name (plant.ini)

**Code reference:** `pcomdb(icom)%name` ([declaration](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/plant_data_module.f90#L147)).

The name of the plant community is a primary key referenced by [plnt\_com](../landuse.lum/plnt_com.md) in [**landuse.lum**](../landuse.lum/). All names in the **plant.ini** file must be unique.
