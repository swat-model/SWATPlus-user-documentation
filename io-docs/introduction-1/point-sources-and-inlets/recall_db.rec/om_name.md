# om_name

**Code reference:** `recall_db(i)%org_min` ([declaration](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/recall_module.f90#L7)).

Organic/mineral constituent name used to match this recall database record to an org_min_name in an outside-source, water-treatment, or water-use concentration definition. This is a name, not a data filename.
