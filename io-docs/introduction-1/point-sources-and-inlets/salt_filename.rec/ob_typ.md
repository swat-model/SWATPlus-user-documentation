# ob\_typ

**Code reference:** `ob_typ` ([declaration](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/recall_read_salt.f90#L16), [read](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/recall_read_salt.f90#L200)).

Character label (`character(len=8)`) indicating the spatial object type on each row.

*(Note: In SWAT+ main (6f515368), this column is parsed into memory but is not used in simulation calculations).*
