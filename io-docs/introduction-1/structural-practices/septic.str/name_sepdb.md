# name (septic.str)

**Code reference:** `sep(isep)%name` ([declaration](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/septic_data_module.f90#L21)).

The name of the septic system record is a primary key referenced by [sep](../../landuse-and-management/landuse.lum/sep.md) in [**landuse.lum**](../../landuse-and-management/landuse.lum/). All names in the **septic.str** file must be unique.
