# name (filterstrip.str)

**Code reference:** `filtstrip_db(ifiltop)%name` ([declaration](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/mgt_operations_module.f90#L31)).

The name of the filter strip record is a primary key referenced by [vfs](../../landuse-and-management/landuse.lum/vfs.md) in [**landuse.lum**](../../landuse-and-management/landuse.lum/). All names in the **filterstrip.str** file must be unique.
