# name (grassedww.str)

The name of the grassed waterway record is a primary key referenced by [grww](../../landuse-and-management/landuse.lum/grww.md) in [**landuse.lum**](../../landuse-and-management/landuse.lum/). All names in the **grassedww.str** file must be unique.
