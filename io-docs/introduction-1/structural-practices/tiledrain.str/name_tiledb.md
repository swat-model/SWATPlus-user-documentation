# name (tiledrain.str)

The name of the tile drain record is a primary key referenced by [tile](../../landuse-and-management/landuse.lum/tile.md) in [**landuse.lum**](../../landuse-and-management/landuse.lum/). All names in the **tiledrain.str** file must be unique.&#x20;
