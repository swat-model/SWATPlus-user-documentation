# name (bmpuser.str)

**Code reference:** `bmpuser_db(ibmpop)%name` ([declaration](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/mgt_operations_module.f90#L60)).

The name of the user BMP record is a primary key referenced by [bmp](../../landuse-and-management/landuse.lum/bmp.md) in [**landuse.lum**](../../landuse-and-management/landuse.lum/). All names in the **bmpuser.str** file must be unique.
