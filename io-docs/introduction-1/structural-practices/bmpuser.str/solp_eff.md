# solp\_eff

**Code reference:** `bmpuser_db(ibmpop)%bmp_sp` ([declaration](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/mgt_operations_module.f90#L64)).

Enter the fraction of soluble phosphorus removed by this BMP (0.0-1.0). For example, 0.2 removes 20% of soluble P. The value is applied as (1 - solp_eff) to reduce the soluble P load.
