# obj\_typ\_no

**Code reference:** `ob_out(ii)%obtypno` ([declaration](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/hydrograph_module.f90#L259)).

Soil water contents of the soil layers can be printed for all HRUs in the same file by setting _obj\_typ\_no_ = 0. For all other outputs, a separate object print record with a unique name has to be defined for each object.&#x20;
