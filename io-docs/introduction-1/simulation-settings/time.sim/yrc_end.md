# yrc\_end

**Code reference:** `time%yrc_end` ([declaration](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/time_module.f90#L23)).

{% hint style="info" %}
If the simulation ends after the last day of the observed climate data, SWAT+ will use simulated climate data for the time period after the end of the observed climate data.
{% endhint %}
