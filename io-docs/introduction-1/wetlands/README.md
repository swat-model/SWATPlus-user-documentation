# Wetlands

Wetlands are HRUs in which ponding of water on the surface is allowed. There are two files that are specific to wetlands:

* Main wetland file: [**wetland.wet**](wetland.wet/)
* Wetland hydrology: [**hydrology.wet**](hydrology.wet/)

For defining the remaining wetland properties, the following reservoir files are used:&#x20;

* Wetland initialization: [**initial.res**](../reservoirs/initial.res/)
* Wetland sediment: [**sediment.res**](../reservoirs/sediment.res/)
* Wetland nutrients: [**nutrients.res**](../reservoirs/nutrients.res/)
* Wetland release: [**res\_rel.dtl**](../decision-tables/lum.dtl/)
