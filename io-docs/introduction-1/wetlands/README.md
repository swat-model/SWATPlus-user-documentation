# Wetlands

Wetlands are HRUs in which ponding of water on the surface is allowed. The following files are specific to wetlands:

* Main wetland file: [**wetland.wet**](wetland.wet/)
* Wetland hydrology: [**hydrology.wet**](hydrology.wet/)
* Wetland salts and constituents: [**wetland.wet_cs**](wetland.wet_cs/)

For defining the remaining wetland properties, the following reservoir files are used: 

* Wetland initialization: [**initial.res**](../reservoirs/initial.res/)
* Wetland sediment: [**sediment.res**](../reservoirs/sediment.res/)
* Wetland nutrients: [**nutrients.res**](../reservoirs/nutrients.res/)
* Wetland release: **res_rel.dtl**
