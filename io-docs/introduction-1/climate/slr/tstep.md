# tstep

Integer field in the station header. The reader stores it and uses the daily layout.

*(Note: In SWAT+ main (6f515368), this column is parsed into memory but is not used in simulation calculations).*

See [cli_smeas.f90](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/cli_smeas.f90#L78-L83).
