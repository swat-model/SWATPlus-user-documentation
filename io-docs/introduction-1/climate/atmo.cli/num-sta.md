# num_sta

Number of station blocks. SWAT+ allocates the station array using this count and reads that many blocks.

See [cli_read_atmodep.f90](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/cli_read_atmodep.f90#L36-L37) and [cli_read_atmodep.f90](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/cli_read_atmodep.f90#L69-L74).
