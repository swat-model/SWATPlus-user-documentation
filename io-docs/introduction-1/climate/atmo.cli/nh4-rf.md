# nh4_rf

Ammonium nitrogen concentration in rain in mg/L. SWAT+ computes the wet load in kg/ha as $0.01 C P$, where $C$ is the selected period concentration and $P$ is daily precipitation in mm.

See [nut_nrain.f90](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/nut_nrain.f90#L44-L65).
