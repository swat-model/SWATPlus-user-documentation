# yr_init

Calendar year of the first monthly or yearly period. Use zero for average annual input. SWAT+ uses this year with the simulation start date to locate the first active record.

See [cli_read_atmodep.f90](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/cli_read_atmodep.f90#L40-L66).
