# tstep

Integer layout selector. Values at or below zero select daily rows. Positive values select subdaily rows, with the number of rows per day taken from the simulation configuration.

See [cli_pmeas.f90](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/cli_pmeas.f90#L83-L92).
