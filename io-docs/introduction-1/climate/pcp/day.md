# day

Calendar day of the month. Input order within each day determines the storage slot.

*(Note: In SWAT+ main (6f515368), this column is parsed into memory but is not used in simulation calculations).*

See [cli_pmeas.f90](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/cli_pmeas.f90#L120-L139).
