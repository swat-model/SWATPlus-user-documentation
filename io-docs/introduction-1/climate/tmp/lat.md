# lat

Station latitude in decimal degrees, from −90 to 90.

*(Note: In SWAT+ main (6f515368), this column is parsed into memory but is not used in simulation calculations).*

See [cli_tmeas.f90](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/cli_tmeas.f90#L88-L93).
