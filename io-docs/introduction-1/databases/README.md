# Databases

There are several databases included in SWAT+:

* Plants/land cover: [plants.plt](plants.plt/)
* Urban land use: [urban.urb](urban.urb/)
* Tillage: [tillage.til](tillage.til/)
* Fertilizer: [fertilizer.frt](fertilizer.frt/)
* Manure: [manure\_db.frt](manure_db.frt/) and [manure\_om.frt](manure_om.frt/)
* Salt and other constituent content of fertilizer: [salt\_fertilizer.frt](salt_fertilizer.frt/) and [fertilizer.frt\_cs](fertilizer.frt_cs/)
* Pesticides: [pesticide.pes](pesticide.pes/) and [pest\_metabolite.pes](pest_metabolite.pes/)
* Pathogens: [pathogens.pth](pathogens.pth/)
* Septic systems: [septic.sep](septic.sep/)
* Groundwater canal connections: [gwflow\_canal.con](gwflow_canal.con/)
