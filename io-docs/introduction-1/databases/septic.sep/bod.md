# bod

**Code reference:** `sepdb(is)%bodconcs` ([declaration](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/septic_data_module.f90#L8)).

The BOD for a conventional system is typically 170 mg/L. The value varies greatly for different types of septic systems (see Table A-1 of Siegrist et al. (2005)).
