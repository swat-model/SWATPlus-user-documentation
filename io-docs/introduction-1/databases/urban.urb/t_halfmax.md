# t\_halfmax

**Code reference:** `urbdb(iu)%thalf` ([declaration](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/urban_data_module.f90#L12)).

Number of days for amount of solids on impervious areas to build up from 0 kg/curb km to half the maximum amount of solids allowed (i.e. 0.5\*[dirt\_max](dirt_max.md)).
