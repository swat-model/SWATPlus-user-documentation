# boron

**Code reference:** `fert_cs(icsi)%boron` ([declaration](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/cs_module.f90#L66)).

Mass of boron per unit mass of fertilizer. The code multiplies this value by the fertilizer application rate to calculate the constituent addition. Use kg constituent per kg fertilizer, rather than an independent kg/ha loading.
