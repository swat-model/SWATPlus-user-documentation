# name

**Code reference:** `fert_salt(isalti)%fertnm` ([declaration](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/salt_module.f90#L54)).

Fertilizer label written as name by the inspected Editor exporter. The model reader stores it as fertnm and selects the composition by fertilizer index, so record order matters.
