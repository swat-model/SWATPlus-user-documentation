# aq\_hlife

**Code reference:** `pestdb(ip)%aq_hlife` ([declaration](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/pesticide_data_module.f90#L12)).
