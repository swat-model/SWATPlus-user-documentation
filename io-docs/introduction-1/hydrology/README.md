# Hydrology

There are four files containing the basic topographical and hydrological properties of HRUs:&#x20;

* [topography.hyd](topography.hyd/) defines the topographic characteristics of the HRUs and routing units,
* [hydrology.hyd](hydrology.hyd/) defines the hydrological characteristics of the HRUs,
* [field.fld](field.fld/) specifies the properties of representative fields,
* [snow.sno](snow.sno/) controls the simulation of snowfall and snowmelt processes.
