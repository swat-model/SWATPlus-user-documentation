# ru_frac

**Code reference:** `lsu_elem(i)%ru_frac` ([declaration](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/calibration_data_module.f90#L225)).

Expansion factor used to weight this HRU or HRU-LTE when SWAT+ aggregates element output to Landscape Unit and regional output. Older SWAT+ Editor files may label this positional column sub_frac.
