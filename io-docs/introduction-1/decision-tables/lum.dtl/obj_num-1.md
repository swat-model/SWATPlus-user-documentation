# obj\_num

**Code reference:** `dtbl_lum(i)%act(iac)%ob_num` ([declaration](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/conditional_module.f90#L19)).

If _obj\_num_ = 0, the action will be performed for all objects of the type specified by [obj](obj.md). If _obj\_num_ > 0, the action will be performed for the object with the specified ID only.&#x20;
