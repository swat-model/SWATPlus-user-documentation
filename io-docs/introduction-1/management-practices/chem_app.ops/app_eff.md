# app\_eff

**Code reference:** `chemapp_db(ichemapp)%app_eff` ([declaration](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/mgt_operations_module.f90#L101)).

Application efficiency is entered as a fraction from 0.0 to 1.0. SWAT+ multiplies the application amount directly by this value; for example, 0.90 applies 90% of the specified amount.
