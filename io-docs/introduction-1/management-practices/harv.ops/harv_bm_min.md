# harv\_bm\_min

**Code reference:** `harvop_db(iharvop)%bm_min` ([declaration](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/mgt_operations_module.f90#L116)).

If the biomass is below _harv\_bm\_min_, the harvest operation will not be performed.
