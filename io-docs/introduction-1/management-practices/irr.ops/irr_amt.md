# amt\_mm

**Code reference:** `irrop_db(irr_op)%amt_mm` ([declaration](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/mgt_operations_module.f90#L7)).

Irrigation application amount in mm. SWAT+ uses this value with eff_frac and sumq_frac to calculate irrigation applied to the land and irrigation runoff.
