# jday

**Code reference:** `shf_db(idlsu)%jday` ([declaration](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/hydrograph_module.f90#L1196)).

Day-of-year value matched together with the channel number. In the file-based shading branch, day 366 uses a fixed shade factor of 0.5 rather than a row lookup.
