# wd

**Code reference:** `sd_chd(idb)%chw` ([declaration](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/sd_channel_module.f90#L21)).

The channel width is defined as the average width of the channel at the top of the channel bank. It is calculated by QSWAT+ using a regression equation relating the channel width to the drainage area of the channel.
