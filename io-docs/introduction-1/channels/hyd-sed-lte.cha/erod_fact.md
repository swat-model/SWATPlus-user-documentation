# erod\_fact

The channel erodibility factor is conceptually similar to the soil erodibility factor used in the USLE equation. Channel erodibility is a function of the properties of the bed or bank materials.

{% hint style="info" %}
A value of **erod\_fact** = 1 indicates that there is no resistance to erosion. A value of **erod\_fact** = 0 is suitable for non-erosive channels.
{% endhint %}
