# Channels

There are a number of SWAT+ files that control the simulation of channel processes. The file  [**channel-lte.cha**](channel-lte.cha/) summarizes the main channel information and references several other files that specify the details:

* [**initial.cha**](initial.cha/) references several files, which specify the initial contents of nutrients and constituents in the water,
* [**hyd-sed-lte.cha**](hyd-sed-lte.cha/) controls the channel hydrology and sediment properties, and
* [**nutrients.cha**](nutrients.cha/) controls the channel nutrient properties.&#x20;
