# ben\_nh3n

**Code reference:** `ch_nut(ich)%rs3` ([declaration](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/channel_data_module.f90#L116)).

Enter this field in mg N/m2*day. After reading it, SWAT+ divides the value by the number of routing time steps per day to obtain the value used for each routing step.
