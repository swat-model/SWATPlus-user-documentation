# const\_n

**Code reference:** `ch_nut(ich)%k_n` ([declaration](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/channel_data_module.f90#L150)).

The Michaelis-Menton half-saturation constant for N defines the concentration of nitrogen, at which algal growth is limited to 50% of the maximum growth rate.
