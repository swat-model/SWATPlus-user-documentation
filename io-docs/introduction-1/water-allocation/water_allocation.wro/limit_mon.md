# limit\_mon

| Object type | Limiting factor                 | Unit     |
| ----------- | ------------------------------- | -------- |
| Channel     | Streamflow                      | m3/s     |
| Reservoir   | Principal volume                | Fraction |
| Aquifer     | Water level depth below surface | m        |

The user needs to specify the limit for each month.&#x20;
