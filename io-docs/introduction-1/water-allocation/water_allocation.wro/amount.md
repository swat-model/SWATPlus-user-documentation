# amount

{% hint style="warning" %}
This is a historical `water_allocation.wro` field. For the reviewed main layout, see [place_of_use.wro](../place_of_use.wro.md) and [point_of_diver.wro](../point_of_diver.wro.md). The original description below is retained as historical reference.
{% endhint %}

If [withdr](withdr.md) = ave\_day, the amount needs to be specified here. If using a Decision Table or a recall file, _amount_ should be set to 0, because the amount will be controlled by the DT or recall file.
