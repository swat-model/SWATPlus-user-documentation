# dtbl

**Code reference:** `canal(ic)%dtbl` ([declaration](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/water_allocation_module.f90#L194)).

The name supplied for the canal outflow decision table. Use `null` to select the simple drawdown calculation controlled by [ddown_days](ddown_days.md).
