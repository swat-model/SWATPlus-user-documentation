# ss

**Code reference:** `canal(ic)%ss` ([declaration](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/water_allocation_module.f90#L202)).

The horizontal distance per unit vertical distance of a canal side. This value describes the sides of the trapezoidal cross section.
