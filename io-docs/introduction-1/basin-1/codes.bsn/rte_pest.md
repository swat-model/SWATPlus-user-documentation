# nostress

**Code reference:** `bsn_cc%nostress` ([declaration](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/basin_module.f90#L38)).

| Code | Option                              |
| ---- | ----------------------------------- |
| 0    | All plant stresses applied          |
| 1    | Turn off all plant stress           |
| 2    | Turn off nutrient plant stress only |
