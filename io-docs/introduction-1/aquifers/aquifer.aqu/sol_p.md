# sol\_p

**Code reference:** `aqudb(i)%minp` ([declaration](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/aquifer_module.f90#L12)).

This is a fixed concentration used throughout the entire period of simulation. Accordingly, groundwater phosphorus loads only vary with groundwater flow.
