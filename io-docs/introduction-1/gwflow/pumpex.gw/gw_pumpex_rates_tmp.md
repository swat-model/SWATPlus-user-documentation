# gw_pumpex_rates_tmp

**Code reference:** `gw_pumpex_rates_tmp` ([declaration](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/gwflow_read.f90#L141)).

The volume requested from this cell on each day of the pumping period. The same value applies throughout that period. The model limits an individual request to the available groundwater storage.
