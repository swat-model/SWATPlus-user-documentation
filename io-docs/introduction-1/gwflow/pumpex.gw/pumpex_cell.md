# pumpex_cell

**Code reference:** `pumpex_cell` ([declaration](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/gwflow_read.f90#L104)).

The groundwater cell from which water is pumped. Keep all pumping periods for the same cell together in the file. Pumping is applied when that cell is active.
