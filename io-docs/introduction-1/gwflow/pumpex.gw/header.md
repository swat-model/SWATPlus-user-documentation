# header

**Code reference:** `header` ([declaration](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/gwflow_read.f90#L45)).

A short text label for the pumping-period row. Despite its Fortran name, this is a value on each data row, not an additional column-header line. The cell identifier determines which cell receives the pumping request.
