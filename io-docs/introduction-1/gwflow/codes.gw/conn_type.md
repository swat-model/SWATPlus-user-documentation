# conn_type

**Code reference:** `conn_type` ([declaration](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/gwflow_module.f90#L28)).

Conn_type determines the type of connection between the groundwater and the overlying soil, either HRU (1) or LSU (2).
