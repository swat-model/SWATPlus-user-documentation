# grid_type

**Code reference:** `grid_type` ([declaration](https://github.com/swat-model/swatplus/blob/6f515368525e7d84089ae0f9d33f4c9115de5679/src/gwflow_module.f90#L34)).

Grid_type specifies the type of grid used in the groundwater model, either "structured" or "unstructured" (USG).
