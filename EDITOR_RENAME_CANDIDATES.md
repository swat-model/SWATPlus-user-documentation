# SWAT+ Editor Rename Candidates (Outdated / Misleading Field Names)

This file tracks input and SWAT+ Editor column names that are **clearly outdated or misleading** relative to what SWAT+ main (`6f515368525e7d84089ae0f9d33f4c9115de5679`) actually computes—for example, legacy labels that describe a different physical quantity or deprecated behavior.

Ordinary abbreviations or naming-style differences that still refer to the same physical quantity (such as `area_ps` vs. `psa` or `evap_co` vs. `evrsv`) are intentionally **excluded**.
